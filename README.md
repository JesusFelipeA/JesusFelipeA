## 🚀 Proyecto destacado
**Sistema de gestión para restaurante de barbacoa** — arquitectura de tres componentes sobre una sola base de datos MySQL:
- API REST en **Express + TypeScript**
- App móvil para meseros en **React Native CLI**
- Panel administrativo en **Laravel 13** (con generación de recibos PDF y métodos de pago como transferencia)
