### 🚀 Proyecto destacado

**Sistema de gestión para restaurante de barbacoa**
Arquitectura de tres componentes sobre una sola base de datos MySQL:

- 🔌 API REST en **Express + TypeScript**
- 📲 App móvil para meseros en **React Native CLI**
- 🖥️ Panel administrativo en **Laravel 13** — recibos en PDF, múltiples métodos de pago

---

### 📌 Logros recientes

- 🍖 Sistema de restaurante con API, app móvil y panel admin sincronizados en tiempo real
- ☁️ Despliegue de proyectos Laravel en AWS EC2 (Amazon Linux 2023) — PHP-FPM, Nginx, migraciones
- 📊 Dashboards interactivos con Python/Streamlit y Power BI para análisis de datos
- 🔧 Laravel en producción sobre hosting compartido `public_html` (IONOS, GoDaddy)
- 📦 Generación de códigos de barras sin librerías descontinuadas
- 📷 Escáner QR nativo en React Native, sin Expo
- 🔐 Autenticación JWT y sesiones persistentes en apps móviles
